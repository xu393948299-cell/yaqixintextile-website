## 执行规则

1. 每个分类页只承担一个主采购意图；标题、摘要、H1 和 CollectionPage 的名称保持同一主题，不堆叠同义词。
2. 产品页继续承担“型号 + 材质 + 用途”的长尾意图，不用产品页抢占父分类的主关键词。
3. Blog 文章链接到一个最相关的分类页，再链接 2 个具体产品页；锚文本使用上表的自然表达。
4. 新增分类页前先检查是否与现有页面的主关键词重复，避免内部关键词自相竞争。
5. A2175 等型号保留在产品页、SKU、结构化数据和用户可见规格中；型号不作为站点分类主题。
